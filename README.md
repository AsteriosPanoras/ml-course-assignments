# Εργασίες Μηχανικής Μάθησης

Εδώ βρίσκονται οι εργασίες του μαθήματος. Κάθε εργασία έχει τον δικό της φάκελο με το notebook και τα δεδομένα της.

| Εργασία | Φάκελος | Θέμα |
|---|---|---|
| 1 | [project1](project1/) | Επιβλεπόμενη μάθηση: πρόβλεψη διαβήτη (Logistic Regression) και πρόβλεψη γλυκόζης (Linear Regression) |
| 2 | [project2](project2/) | KNN: πρόβλεψη ικανοποίησης επιβατών αεροπορικής εταιρίας, και πρόβλεψη χρονοσειρών (δείκτης δολαρίου) με Linear Regression |
| 3 | [project3](project3/) | Αξιολόγηση μοντέλων KNN: πρόβλεψη κατηγορίας έλλειψης ύπνου και σκορ κούρασης με Extended Holdout, Cross-Validation και Nested Cross-Validation |
| 4 | [project4](project4/) | Naive Bayes: αναγνώριση αναρτήσεων πραγματικών φυσικών καταστροφών με TF-IDF και GaussianNB |
| 5 | [project5](project5/) | Δέντρα Απόφασης: πρόβλεψη πόσιμου νερού με Decision Tree, επιλογή υπερπαραμέτρων με cross-validation, dtreeviz και σημαντικότητα χαρακτηριστικών |
