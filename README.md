# Εργασίες Μηχανικής Μάθησης

Εδώ βρίσκονται οι εργασίες του μαθήματος. Κάθε εργασία έχει τον δικό της φάκελο με το notebook και τα δεδομένα της.

| Εργασία | Φάκελος | Θέμα |
|---|---|---|
| 1 | [project1](project1/) | Επιβλεπόμενη μάθηση: πρόβλεψη διαβήτη (Logistic Regression) και πρόβλεψη γλυκόζης (Linear Regression) |
| 2 | [project2](project2/) | KNN: πρόβλεψη ικανοποίησης επιβατών αεροπορικής εταιρίας, και πρόβλεψη χρονοσειρών (δείκτης δολαρίου) με Linear Regression |

## Εργασία 1
- Notebook: [project1/project1.ipynb](project1/project1.ipynb)
- Δεδομένα: [project1/diabetes.csv](project1/diabetes.csv)

Για να τρέξει στο Google Colab, ανεβάζεις και το `diabetes.csv` στο ίδιο περιβάλλον πριν το τρέξεις.
